# Greeting Skill

当该技能被触发时（例如用户说"你好"、"hi"、"在吗"等问候语，或一次新会话的开始）：

1. 用与用户相同的语言简短回礼问候（中文用户用中文，英文用户用英文）。
2. 主动询问用户需要什么帮助，控制在 1-2 句话内。
3. 不要客套堆砌，不要重复问候；问候完成后立即回到任务本身。

## 示例

- 用户："你好"
- 回复："你好！有什么可以帮你的？"
